# Axiom 1.0 — Performance Baseline

*Maintainer artifact. Not shipped.* Version `1.0.0-rc.1`. **Status: NOT RECORDED — required before `1.0.0`.**

## Scope (spec §55-59)

1.0 sets no arbitrary performance target, but the major paths MUST be characterized and a
baseline recorded:

- graph admission (`validateGraph`, `compileToIR`, `compileToServerIR`)
- action execution (simple; `for-each`; nested `invoke`)
- query execution (memory + SQLite provider; keyset pagination; aggregate)
- authorization evaluation (policy; legacy; conjunction)
- workflow transition (action step; branch; timer; event wait)
- live-query update (delta compute; reset)
- migration startup (fingerprint compare; multi-step plan)
- distributed coordination (claim / fence / reclaim)
- AgentAPI inspection (`explainGraph`, dependency traversal, `analyzeAuthorization`)

## Rules (spec §56)

Performance optimization MUST NOT weaken semantics — specifically no authorization caching
beyond validity, no stale query visibility, no fencing bypass, no transaction weakening, no
effect-identity change, no nondeterministic ordering where ordering is semantic. Any such
optimization is a `SEMANTIC` change and stops 1.0 hardening (spec §6).

## Resource / leak behavior (spec §57-59)

Sustained-workload checks for listener / timer / subscription / connection leaks, unbounded
maps, abandoned workflow handles, provider resource leaks; documented retention / cleanup
responsibilities for workflow history, effect records, event-dedup records, subscription
cursors, live-query subscribers, blob intents, migration records, coordination leases, cache
entries — as **host/provider** responsibilities, not portable semantics.

## Existing signal

The fast-tier suite (`~80s`) and soak-tier (`~7min`, `AXIOM_*` at 50/25) wall-clock numbers
in `CLAUDE.md` are the only recorded timing today. No micro-benchmark harness exists.

## Required

A `bench/` harness producing a committed `reports/1.0-performance-baseline.json` with median
+ p95 for each path above on a stated machine/Node, plus the leak-check results.
