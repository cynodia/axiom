# Axiom 1.0 — Upgrade & Cross-Runtime Regression Validation

*Maintainer artifact. Not shipped.* Version `1.0.0-rc.1`.

## Upgrade 0.17 → 1.0 (spec §60-61)

**Design (verified by construction; execution against packed artifacts is a campaign item):**

- `semanticContractChanged == false` — no `packages/*/src` change between the final 0.17
  package set and `1.0.0-rc.1`. Therefore:
  - every graph that admitted under 0.17 admits under 1.0 unchanged;
  - `semanticFingerprint`, `schemaFingerprint`, Server IR contract labels and
    `AuthorityCompatibilityKey` are unchanged for every graph;
  - persisted state, durable workflow records, migration metadata and live-query cursors
    minted under 0.17 remain valid;
  - no graph edit is required because the version became `1.0`.
- Stated normatively in `docs/COMPATIBILITY.md` → "Upgrading from 0.17".

**Required execution (campaign):** install the final 0.17 tarballs, build+run a fixture app,
persist state + a workflow + migration metadata + a live cursor; swap to the `1.0.0-rc`
tarballs; assert admission, fingerprint compatibility, and that all persisted/durable
artifacts still load and progress. Mixed-version matrix per spec §41 (same fingerprint /
presentation-only diff / executable semantic diff / authz semantic diff / provider contract
diff) — compatible accepted only where the contract permits, incompatible fails closed.

## Cross-runtime regression (spec §79-82) — NOT RUN

This is **not** a new Track A. It is the gate that 1.0 hardening did not perturb the frozen
semantics. Requires the independent Python runtime (out of this repository):

- Frozen portable baseline against `{1.0-rc reference runtime}` and `{independent Python
  runtime}` → required: `no new R1`, `no new R2`, `no new S1/S2 semantic gap`.
- Distributed portable baseline four-way where applicable:
  `semantic(reference-1) == semantic(reference-N) == semantic(independent-1) == semantic(independent-N)`.
- Security regression: `unauthorized successes = 0`, `principal leaks = 0`,
  `cursor bearer leaks = 0`, `stale fenced commits = 0`, `mixed-version fail-open = 0`.
- Durability regression: `lost durable work = 0`, `duplicate logical work = 0`,
  `migration corruption = 0`, `invalid workflow terminal state = 0`.
- Totality regression: `native crashes at supported untrusted boundaries = 0` for the final
  malformed corpus.
