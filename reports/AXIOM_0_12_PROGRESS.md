## Release classification (spec12 §110): **A — DISTRIBUTED AUTHORITY**

Fencing proven (real OS processes + SIGKILL). Effect delivery accurately modelled — no false
exactly-once. Scheduler safe. Durable work reclaimable. Compatibility fail-closed. No
semantic escape. All twelve §105 release blockers satisfied — see the implementation report.

## Invariants (release-blocking — spec12 §105)

- Two authorities never validly own the same `(resourceId, generation)`.
- A stale owner cannot commit completion/retry/cursor state after `generation` advances.
- One logical schedule firing never becomes two because N authorities poll.
- A duplicate stable external event never becomes two semantic events; a same-id/different-payload event is an explicit `EVENT_ID_CONFLICT`.
- An effect retry never creates a second `logicalEffectId`.
- A crash never permanently strands durable work; failover never loses committed work.
- An incompatible / older-build authority never executes new-schema work.
- Ordinary multi-authority operation needs no application SQL / locks / `NativeOperation`.
- Provider-native contention (`SQLITE_BUSY`) never leaks as a semantic result.
- Authoritative cache is never stale past the declared bound (= one revision check).
- A subscription stale owner never overwrites a newer cursor.
- Physical external-effect exactly-once is never claimed.

## Notes

- `axiom.server.v7` unchanged; frozen `v1..v7` IR schemas + `v1..v5` conformance fixtures
  restored byte-identical after any `conformance:generate` / `schema:generate` run.
- Cross-process reference tests fork real OS processes (pattern established by
  `migration-race.test.ts`); `AXIOM_RACE_TRIALS` / `AXIOM_AUTHORITIES` env overrides.
- **Server test script now pins `--test-concurrency=1`** (`packages/server/package.json`).
  `node --test`'s default file-level parallelism (worker-thread pool) is nondeterministically
  unstable on the pinned Node build — a pre-existing latent flake (random non-forking files
  such as `persistence.test.js` / `migration-eval.test.js` failing to register their tests),
  independent of 0.12, but the three §83-mandated real-process forking suites make it
  frequent. Serial file execution is fully deterministic (410/410 repeatably) and costs
  ~10s. Only the server package is affected.
