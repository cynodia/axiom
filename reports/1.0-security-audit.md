# Axiom 1.0 — Security Audit

*Maintainer artifact. Not shipped.* Version `1.0.0-rc.1`. **Status: NOT RUN — campaign required before `1.0.0`.**

## Scope (spec §24-26, §64-65)

A dedicated fresh audit, independent of feature development, covering:

- Authorization: default-deny for privileged ops; three-valued security-absence semantics
  (`axiom.authz.v3`); legacy + policy conjunction; every invocation path (direct / workflow
  step / scheduler / event / retry / failover); `query.read`; row-authorization ordering
  relative to filter/sort/limit/pagination/aggregation; live open / resume; workflow
  inspect / history / cancel; state & provider mutation; principal preservation; cursor
  principal binding.
- Adversarial principals: missing identity / role / tenant; malformed credential; partial
  security object; unexpected field types; revoked privilege; principal change across
  resume. Required: `0 unauthorized successes`, `0 fail-open evaluation errors`.
- Credential / secret leakage sweep: logs, diagnostics, AgentAPI output, cursor
  representations, workflow history, effect records, event records, provider errors.
- The 12 classes in spec §64: authorization bypass, principal confusion, cursor replay,
  workflow ownership, event spoofing / dedup abuse, provider trust boundaries,
  NativeOperation boundary, secret leakage, malformed input, resource exhaustion,
  distributed fencing, mixed-version fail-open.

## Gate (spec §65)

`1.0.0` MUST NOT ship with unresolved `CRITICAL` or `HIGH`. `MEDIUM` requires explicit
disposition.
