## SIGKILL / crash campaign (spec §18–19)

`packages/server/test/workflow-crash-matrix.test.ts` and `workflow-mixed-build.test.ts`
**fork real OS authority processes and `SIGKILL` / `SIGSTOP` them** at durable boundaries,
then restart and verify recovery. Run at two intensities:

| tier | knobs | result |
| --- | --- | --- |
| soak (`npm run test:soak`) | `AXIOM_WF_TRIALS=50 AXIOM_WF_MIXED_TRIALS=25` | full suite **1707 / 1707 pass**; server workspace ~6.5 min |
| elevated (this campaign) | `AXIOM_WF_TRIALS=120 AXIOM_WF_MIXED_TRIALS=60 AXIOM_RACE_TRIALS=60 AXIOM_AUTHORITIES=8` | **63 tests, 63 pass, 0 fail**, 505 s |

Marquee elevated cases (all pass):

- `SIGKILL after the ActionDef commit, before the workflow transition — 120 trials, exactly once` (160 s)
- `SIGKILL the event‑routing authority before the workflow transition — 120 trials`
- `replaying the same logical event (live + across restart) yields one transition`
- `SIGSTOP the lease owner, another authority advances, the resumed stale write is refused` (fencing)
- `2 / 8 authorities claim the same runnable workflow — exactly one logical transition`
- `build B (different wait‑event target / timer duration / action target) refuses an A instance across real processes — 60 trials` ×3
- `a presentation‑only build B continues an A instance — 60 trials`

Boundaries exercised (from the crash‑matrix + `spec14pt2`/`pt3` corpus): before/after
action commit, before/after workflow checkpoint, before/after effect dispatch, before/after
effect completion record, during event processing, during timer firing, while holding a
distributed lease, after lease expiry, after reclaim, before/after subscription cursor
persistence.
