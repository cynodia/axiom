## Findings from the RC-preparation pass

### PKG-1 — `engines` was undeclared — **RESOLVED (this pass)**

- **Class / severity:** PKG / MEDIUM.
- **What:** No published manifest declared `engines.node`, while the project requires Node
  ≥ 22 (test runner glob; `node:sqlite` 22.5+ for the SQLite adapters).
- **Fix:** `"engines": { "node": ">=22.0.0" }` added to all 8 published/facade manifests.
  No older Node is claimed because none is tested (spec §50).
- **Semantic change:** none.

### DOC-1 — 1.0 semantics were not discoverable without the 0.x roadmap — **RESOLVED (this pass)**

- **Class / severity:** D1 / MEDIUM.
- **What:** A new user had to infer from `specs/` + `CLAUDE.md` that "1.0 == frozen 0.17",
  and there was no single statement of the SemVer / compatibility policy or the
  normative-vs-informative document classes.
- **Fix:** `docs/COMPATIBILITY.md` (NORMATIVE) — the canonical entry: 1.0 == frozen 0.17;
  authoritative-information table; portable-profile boundaries; `axiom.conformance.1.0`
  baseline pointer; patch/minor/major policy; semantic-bug handling (spec §63); diagnostic
  stability classes; 0.17 → 1.0 upgrade statement; known limitations. Linked from both
  README doc-maps.
- **Semantic change:** none.

### INFO-1 — alpha-era ambiguity sweep is clean

- **Class:** D1 / INFO.
- Grep across `docs/`, `README.md`, package READMEs, facade entry points for `for now`,
  `TBD`, `TODO`, `might change`, `implementation decides`, `reference behavior`,
  `provisional`, etc. Every hit is a deliberate, correct statement — most notably
  `implementation-defined` appears only where 0.17 SEM-2 made a diagnostic code non-semantic,
  and `EXPRESSIONS.md` explicitly states coercion is **not** implementation-defined. No
  load-bearing 1.0 rule is left provisional. No change required.

### INFO-2 — `semanticContractChanged == false` verified structurally

- **Class:** N1 / INFO.
- No file under any `packages/*/src` changed in this pass. Server IR `axiom.server.v9`,
  authz `axiom.authz.v3`, `SEMANTIC_FINGERPRINT_VERSION` unchanged. Fast-tier fingerprint /
  compatibility tests (`core/test/semantic-identity.test.ts`,
  `server/test/authorization-identity.test.ts`, `authority-identity` tests) green.
