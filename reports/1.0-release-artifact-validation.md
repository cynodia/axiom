## Deep‑import audit (spec §5)

Every import specifier in every shipped `dist/*.js` extracted: external references are only
`@cynodia/axiom-{core,runtime,compiler,agent-api,server}` (all declared deps) and `node:`
builtins. **No** import escapes its package, reaches `src/` / `dist/internal/` / a
monorepo‑relative path / `node_modules`. The five consumer projects
(`reports/1.0-consumer-project-validation.md`) build and run using only documented
package‑root imports.

**Accidental required deep imports = 0.**

## RC tested from packed artifacts (spec §3, §45)

All final validation in this campaign — consumer projects, installation matrix, CLI checks,

## Final artifact rule (spec §45)

`1.0.0` is expected to differ from `1.0.0-rc.1` only in the version string, applied by
`npm run version:set` across every manifest / doc / generated stamp — exactly the shape of
the `0.17 → 1.0` delta (`reports/1.0-upgrade-validation.md`). Before `npm publish`, a final
packed `1.0.0` candidate MUST be rebuilt and re‑run through `release:verify` +
`release:consumer-test` + this audit; RC evidence is not to be relabelled `1.0.0` evidence.

**Release artifact validation: PASS.**
