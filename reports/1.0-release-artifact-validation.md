# Axiom 1.0 — Release Artifact Validation

*Maintainer artifact. Not shipped.* Version `1.0.0-rc.1`. **Status: NOT RUN against packed artifacts — required before `1.0.0`.**

## Principle (spec §84)

The release decision MUST validate the **exact artifacts intended for publication**, not
source/workspace packages.

## Scope (spec §50-54, §76-78, §84-85)

- **Installation matrix** (spec §50): supported Node versions, package-manager versions, OS
  families, ESM/CJS expectations, TypeScript requirements — record only what is actually
  tested. `engines.node` is now `>=22.0.0`.
- **Clean consumer projects** (spec §51): one each for application author / server-runtime
  consumer / provider implementer / tooling-AgentAPI consumer / conformance runner —
  installing **only** the candidate tarballs, no monorepo path, no undeclared dependency, no
  source-tree dependency.
- **Tarball audit** (spec §52): required `dist` + `.d.ts` + schemas + docs present; no
  private test data, no secrets, no internal databases; `package.json` `exports` correct;
  license metadata correct; declaration maps deliberately not shipped.
- **Dependency & supply-chain / provenance** (spec §53-54, §85): security / license /
  maintenance review; record git commit, toolchain, lockfile hash, Node version, build &
  test commands, conformance version, artifact hashes; confirm the test suite ran against
  the same artifacts.
- **RC from packed artifacts** (spec §78): install RC tarballs in the clean consumer
  projects; verify install / import / compile / execute / inspect / conformance / provider
  integration.

## Existing tooling (ready to run on the RC)

`npm run release:prepare` → `clean` → `build` → `test:soak` → `test:browser` → `pack` →
`verify-packages` (`scripts/verify-packages.mjs`: no `file:`/`link:`/`workspace:` ranges in
any tarball; LICENSE/README not drifted; every `docs/` file packed) → `discoverability-probe`
(`scripts/discoverability-probe.mjs`: reconstructs the cold-agent view from the tarball) →
`consumer-test` (`scripts/consumer-test.mjs`: Counter app from tarballs; `--from-registry`
variant; per-command `axiom <cmd> --help` + `--json` smoke). `npm run release:verify-registry`
(`scripts/verify-registry.mjs`) confirms every publishable package resolves at the exact
version with a correct `bin` map.

## Required

Run `release:prepare` end-to-end on `1.0.0-rc.1`, then the five audience consumer projects
and the tarball-content audit, and commit the reproducibility record (spec §85).
