# Axiom 1.0 — API Stability

*Maintainer artifact. Not shipped.* Version `1.0.0-rc.1`.

## Statement

Axiom 1.0 commits to the `1.x` compatibility policy in `docs/COMPATIBILITY.md` (NORMATIVE).
In short:

- **Portable semantic meaning** is the frozen 0.17 contract and does not change across
  `1.x` except by an explicitly versioned expansion (minor) or an incompatible change
  (major). A graph valid under `1.0` keeps its meaning under every `1.x`.
- **Public API surface**: additive in minor releases; no removal or incompatible signature
  change without a major. Accidental internal exports are not covered by this guarantee and
  may be withdrawn in a minor once identified.
- **Diagnostics**: stability by class (`STABLE_MACHINE_CODE` / `STABLE_CATEGORY` /
  `IMPLEMENTATION_DEFINED` / `DEBUG_ONLY`) — see `docs/COMPATIBILITY.md`.
- **CLI**: the `--json` machine surface is the automation contract; human prose formatting is
  not.
