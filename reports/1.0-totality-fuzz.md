## Finding TOT‑1 (SEC/OPS · LOW · non‑blocking)

`server.handle({kind:'snapshot', sinceRevision: X})` propagates a native
`TypeError: Cannot convert object to primitive value` (instead of a structured
`MALFORMED_REQUEST`) when `X` is a null‑prototype object, an array containing one, or an
object whose `toString` / `[Symbol.toPrimitive]` throws — because a diagnostic‑message
string coercion runs before the integer check. Ordinary malformed values (`{}`, `[1,2]`,
`10n`, `-1`, `1.5`, `"x"`) already return `MALFORMED_REQUEST`. **Not reachable over any
JSON transport** — `JSON.parse` cannot express a null prototype or a function/throwing
`toString`; verified that `serveOverHttp` turns `{}` and `[{},{}]` into `MALFORMED_REQUEST`.
Read‑only, fail‑closed. Fix: guard `sinceRevision` with `typeof` / `Number.isInteger`
before any string coercion.

**Totality fuzz: PASS.** `native crashes = 0` at every wire‑reachable untrusted boundary;
`hangs = 0`. TOT‑1 (in‑process‑only, read‑only) and H1‑1 (non‑boundary) are non‑blocking.
