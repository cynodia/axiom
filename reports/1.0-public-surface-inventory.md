## `engines`

Declared `">=22.0.0"` on every published manifest in this pass (previously absent — see
`1.0-findings.md` PKG-1). Rationale: the only environment the suite is tested on is Node
≥ 22 (`node --test` native glob); the optional SQLite adapters use `node:sqlite` (Node
22.5+), lazily imported with a documented memory fallback. No older Node is claimed because
none is tested (spec §50).

## Classification — status

Per-symbol classification into `STABLE` / `ADVANCED_STABLE` /
`INTERNAL_ACCIDENTALLY_EXPORTED` / `DEPRECATED` / `EXPERIMENTAL_POST_1_0` (spec §8) is a
**campaign item** — ~1330 symbols. This pass records the **methodology** and the
**category-level** picture; the symbol-by-symbol sign-off, and removal of any accidental
export, is required before `1.0.0`.

### Methodology

1. A symbol is **STABLE** if it is named in a `docs/` NORMATIVE document or in
   `docs/AGENT_REFERENCE.md`, or is a builder / node-def type / diagnostic-code map / public
   contract constant an application or a conforming runtime must use.
2. **ADVANCED_STABLE** — supported but for runtime/provider/tooling implementers, not
   application authors (e.g. `serverIRStructuralProblems`, `createSqliteDataProvider`,
   conformance runners, `AuthorityCompatibilityKey`).
3. **INTERNAL_ACCIDENTALLY_EXPORTED** — reachable from `index.ts` but never documented and
   not part of any contract (candidate for removal or `@internal`).
4. **DEPRECATED** — superseded but retained (`ActionDef.preconditions`/`failureModes`
   positional form vs `guards`; `role: 'danger'` / `density: 'normal'` spellings).
5. **EXPERIMENTAL_POST_1_0** — none should ship in `1.0.0`; anything genuinely provisional
   is removed or gated.

## Export discipline (spec §9)

`scripts/consumer-test.mjs` already builds throwaway external projects from **tarballs only**
and exercises the public API; `--from-registry` does the same from the live registry. A lint
that fails the build on `dist/internal` / `src/` / monorepo-relative deep imports in
consumer code is **not yet present** and is a campaign item.
